# LOS201 - Embedded Linux Labs

This repository contains practical laboratory work
for the LOS201 Embedded Linux course.

## Lab 01 - Embedded Linux System Setup

- Linux Kernel 5.15 configuration
- U-Boot 2022.04 configuration
- BusyBox 1.35.0 configuration
- Initramfs preparation
- Kernel and bootloader build outputs

## Lab 02 - Linux Device Driver

- Driver source code and related files
- Baseline and configuration files
- MTD-related work
- Root filesystem files
- Test and output files

## Lab 03 - Embedded Linux Debugging and Testing

- Application programs
- Debugging tools
- Test scripts
- Execution logs
- Initramfs startup configuration
- Kernel module used for testing

## Repository Structure

lab01/ - Lab 1 files
lab02/ - Lab 2 files
lab03/ - Lab 3 files

## Notes

Large Linux kernel source trees and unnecessary
build artifacts are excluded from this repository.
