018 | II. Kiến thức nền cần có
019 | 2.1. Quản lý bộ nhớ trong Linux (Chapter 16)
020 | Virtual memory: mỗi process có address space riêng, kernel space và user space được phân tách.
021 | Heap management: malloc()/free() và vòng đời của heap allocation – fragmentation, leak.
022 | Memory map của process: text, data, BSS, heap, stack, mmap regions – đọc /proc/PID/maps.
023 | Memory leak: bộ nhớ được cấp phát nhưng không bao giờ được giải phóng, tích lũy dần theo thời gian.
024 | Per-process memory: VSZ (Virtual Size) vs RSS (Resident Set Size) – sự khác biệt quan trọng.
026 | 2.2. Development Tools (Chapter 17)
027 | GDB (GNU Debugger): breakpoint, watchpoint, backtrace, print, x (examine memory), info registers.
029 | strace: intercept và log tất cả system calls của một process, xem arguments và return values.
030 | perf: Linux performance analysis tool – perf stat, perf record, perf report, flame graph.
031 | Valgrind / memcheck: công cụ dynamic analysis phát hiện memory error, leak, invalid access.
033 | 2.3. Kernel Debugging (Chapter 18)
034 | Thách thức khi debug kernel: không có OS bên dưới để đỡ, crash là fatal, hạn chế về tool.
035 | printk và dmesg: debug cơ bản bằng log message với log level (KERN_DEBUG, KERN_INFO, KERN_ERR).
036 | KGDB: kernel GDB stub cho phép debug kernel qua serial hoặc network từ host GDB.
037 | Oops và panic: cấu trúc của kernel crash dump, cách đọc backtrace từ kernel log.
039 | 2.4. Linux và Real-Time (Chapter 19)
040 | Real-time: đảm bảo deadline – hard RT (miss = system fail) vs soft RT (miss = degraded).
041 | Kernel preemption: PREEMPT_NONE, PREEMPT_VOLUNTARY, PREEMPT (Desktop), PREEMPT_RT (Fully Preemptible).
042 | PREEMPT_RT patch: chuyển hầu hết interrupt handler thành kernel thread, loại bỏ non-preemptible section.
043 | cyclictest: đo worst-case latency bằng cách đo sai số giữa wake-up dự kiến và thực tế.

458 | #include <stdlib.h>
459 | #include <string.h>
460 | #include <math.h>
461 | #include <time.h>
463 | #define ARRAY_SIZE  100000
464 | #define ITERATIONS  50
466 | /* Hàm tính toán nặng – CPU bound */
467 | double heavy_compute(double *arr, int n) {
468 |     double result = 0.0;
469 |     for (int i = 0; i < n; i++) {
470 |         result += sqrt(arr[i]) * log(arr[i] + 1.0);
471 |     }
472 |     return result;
473 | }
475 | /* Hàm tìm kiếm tuyến tính – O(n) */
476 | int linear_search(int *arr, int n, int target) {
477 |     for (int i = 0; i < n; i++)
478 |         if (arr[i] == target) return i;
479 |     return -1;
480 | }
482 | /* Hàm I/O – nhiều system call */
483 | void io_intensive(int count) {
484 |     FILE *f = fopen("/tmp/perf_test.txt", "w");
485 |     for (int i = 0; i < count; i++)
486 |         fprintf(f, "Line %d: measurement data\n", i);
487 |     fclose(f);
488 | }
490 | int main(void) {
491 |     printf("=== Perf Target App – LAB-03 ===\n");
493 |     /* Khởi tạo array */
494 |     double *darr = malloc(sizeof(double) * ARRAY_SIZE);
495 |     int    *iarr = malloc(sizeof(int)    * ARRAY_SIZE);
496 |     for (int i = 0; i < ARRAY_SIZE; i++) {
497 |         darr[i] = (double)(i + 1);
498 |         iarr[i] = i;
499 |     }
501 |     printf("[1] CPU-intensive computation...\n");
502 |     double total = 0;
503 |     for (int iter = 0; iter < ITERATIONS; iter++)
504 |         total += heavy_compute(darr, ARRAY_SIZE);
505 |     printf("    Result: %f\n", total);
507 |     printf("[2] Linear search (1000 times)...\n");
508 |     for (int i = 0; i < 1000; i++)
509 |         linear_search(iarr, ARRAY_SIZE, ARRAY_SIZE - 1);
511 |     printf("[3] I/O intensive (write 10000 lines)...\n");

514 |     free(darr); free(iarr);
515 |     printf("Done.\n");
